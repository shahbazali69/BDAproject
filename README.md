# Data Analytics & Visualization Project

This project is set up for collaborative big data analysis and visualization.

## Setup Instructions
1. Clone the repository: `git clone <your-github-repo-url>`
2. Create and activate the virtual environment:
   - Mac/Linux: `source venv/bin/activate`
   - Windows: `venv\Scripts\activate`
3. Install dependencies: `pip install -r requirements.txt`

## Tech Stack
* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Visualization:** Streamlit (interactive web dashboards), Plotly/Matplotlib
* **Version Control:** Git & GitHub
